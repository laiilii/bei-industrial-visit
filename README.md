Project website HTML, CSS, dan JavaScript untuk dokumentasi kunjungan industri ke Bursa Efek Indonesia.

## Cara menjalankan
1. Ekstrak folder `BEI-INDUSTRIAL-VISIT`.
2. Buka `index.html` menggunakan browser (Chrome/Edge/Firefox).
3. Pastikan folder `assets`, `css`, dan `js` tetap berada di lokasi yang sama dengan `index.html`.

## Menambahkan video vlog 90 detik
1. Edit video vlog hingga durasinya 90 detik.
2. Ekspor/simpan sebagai MP4 dengan nama `vlog-bei.mp4`.
3. Letakkan file tersebut di `assets/video/vlog-bei.mp4`.
4. Buka ulang `index.html`. Video akan tampil pada bagian Video Documentation.

## Foto
Sepuluh foto dokumentasi yang dikirim telah dimasukkan ke `assets/images/bei-01.jpg` sampai `bei-10.jpg`.
